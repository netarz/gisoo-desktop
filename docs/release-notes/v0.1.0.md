First release of Gisoo Desktop for Windows and macOS.

- Projects as folders in the sidebar, each with its own chats; several chats can work at the same time.
- The full Gisoo agent from Gisoo for VS Code 1.0.6: plans, approved diffs, checkpoints, permission modes, every model on your account.
- Chats from Gisoo for VS Code, Claude Code and Codex for the same folder appear under the project and can be continued.
- Project instructions, commands, skills and memory are read from the project's own folder.
- MCP servers from Gisoo, Claude Code and Codex configs, with approval for project servers; AStack's shared brain in AStack projects.
- Sign in with your Gisoo account or an API key. Persian and English, right to left, light and dark.

**Downloads:** `Gisoo-Setup-0.1.0.exe` (Windows), `Gisoo-0.1.0-arm64.dmg` (Apple silicon), `Gisoo-0.1.0-x64.dmg` (Intel Mac). Check them against `SHA256SUMS.txt`.

The installers are not code-signed yet. On Windows choose *More info*, then *Run anyway*. On macOS right-click the app, choose *Open*, then *Open* again.
