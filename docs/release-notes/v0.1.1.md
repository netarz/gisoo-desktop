The macOS app is now signed and notarized.

- macOS: signed with our Apple Developer ID and notarized by Apple, so it opens without the "cannot be opened" warning.
- Windows: not code-signed yet. Windows may show "Windows protected your PC"; choose *More info*, then *Run anyway*.
- Same features as 0.1.0.

**Downloads:** `Gisoo-Setup-0.1.1.exe` (Windows), `Gisoo-0.1.1-arm64.dmg` (Apple silicon), `Gisoo-0.1.1-x64.dmg` (Intel Mac). Check them against `SHA256SUMS.txt`.
